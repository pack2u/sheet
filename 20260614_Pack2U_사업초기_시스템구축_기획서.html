02
Background & Problem

사업 배경 및 현재 문제 정의

🔴 현재 상황: 100% 수작업 운영

Pack2U는 일회용 식품용기·위생용품을 50개 이상의 오픈마켓에서 판매하고, 30개 이상의 협력업체를 통해 대리발송하는 중규모 도매 유통 사업체입니다. 현재 모든 업무가 수작업으로 이루어지고 있습니다.

  • 주문 취합: 마켓별로 별도 로그인 → 수동 엑셀 복사 → 수기 합산
  • 협력업체 발주: 카카오톡·이메일로 개별 연락 → 전화 확인
  • 송장 매핑: 업체가 보낸 송장번호를 엑셀에 수동 대입 (일일 4.5시간 소요)
  • ERP 입력: 이카운트 ERP에 판매전표를 직접 수기 입력
  • 상품 이미지: 외부 스튜디오 촬영 의뢰 (7~10일 소요, 건당 수십만 원)
  • 상세페이지: 디자이너 수작업 HTML 코딩 (1제품당 3~5일)
  • 영상 콘텐츠: 외주 제작 (건당 50~200만 원, 2~3주 소요)
  • 물류 피킹: 사람이 직접 창고를 도보로 이동하며 제품 수집

⚠️ 문제 진단: 성장 병목 구간

1. 시간 유실 — 전체 근무시간의 75%

단순 반복 데이터 입력과 복사·붙여넣기에 매일 4.5시간 이상을 낭비하고 있어, 영업·소싱·고객관리 등 핵심 업무에 집중할 수 없습니다.

2. 확장 불가능 — SKU 증가 시 붕괴

현재 3,500개 SKU를 수기로 관리하는 것이 한계에 도달했으며, 신규 500개 제품 추가 시 당일 배송 체계가 붕괴될 위험이 있습니다.

3. 콘텐츠 부재 — 마케팅 경쟁력 저하

제품 이미지·영상 콘텐츠 제작이 외주에 전적으로 의존하고 있어, 신상품 런칭까지 2~3주가 소요되고 비용도 과다합니다.

4. 휴먼 에러 — 연간 수천만 원 손실

수기 입력으로 인한 오발송, 단가 오류, 송장 미매핑 등의 실수가 연간 1,800만 원 이상의 직접 손실을 유발하고 있습니다.

Core System #1

주문관리 & 상품정보 통합 시스템 구축 계획

전체 시스템의 중추 신경이 될 주문·상품·재고 통합 관리 플랫폼을 구글 스프레드시트 + Apps Script 기반으로 구축합니다. 이 시스템이 완성되어야 이후 모든 연동 모듈이 동작할 수 있습니다.

📐 구현할 핵심 모듈 설계

1
상품정보 마스터 시트: 3,500개 SKU의 품목코드·품명·원가·판매가·상태·재고수량을 관리하는 중앙 DB 시트를 설계합니다. A열 상태 체계(판매중/품절/단종/소싱중 등)를 정의합니다.
2
주문 수집 파이프라인: 팩투유 솔루션을 통해 스마트스토어·쿠팡·11번가 등 전 오픈마켓 주문을 마스터 시트로 자동 당겨오는 수집 모듈(fetchItem.gs)을 개발합니다.
3
업체별 대리발송 분리 필터: 자체 출고 건과 외부 위탁 건을 자동 분류하여 `업체별대리발송` 탭으로 필터링하는 로직을 구현합니다.
4
V4 광역 안전 엔진: 엑셀 헤더를 자동 읽어 블랙리스트 열을 배제하고, 이름/전화번호를 정밀 타겟팅하여 송장번호를 매칭하는 지능형 엔진을 개발합니다.
5
쇼핑몰별 역분배 탭: 스마트스토어·쿠팡 등 쇼핑몰별 전용 탭에 VLOOKUP 기반 자동 역분배 수식 체계를 설계합니다.

⚙️ 기술 사양 및 제약 조건

플랫폼: Google Sheets + Apps Script (V8 런타임)

Core System #2

이카운트 ERP 완전 연동 모듈 구축 계획

현재 수기로 입력하는 이카운트 ERP와의 모든 데이터 교환을 REST OAPI를 통해 100% 자동화하는 브리지 모듈을 개발합니다.

🔗 구현할 연동 파이프라인

1
3단계 인증 시스템: ecountStep1(로그인) → Step2(세션 확인) → Step3(데이터 전송) 구조를 설계합니다. 세션 ID의 특수문자(%, +) 인코딩 손상을 방지하기 위해 PropertiesService에 안전 보관합니다.
2
품목 상태 동기화: 이카운트 품목그룹3(CLASS_CD3) 코드 체계(9001~9007)를 정의하고, 상품정보 A열 상태와 양방향 동기화합니다.
3
판매전표 자동 업로드: 통합 발주 DB에서 이카운트 /OAPI/V2/Sale/SaveSale API로 판매전표를 자동 등록합니다. P열에 '이카운트 업 완료' 플래그를 마킹하여 중복 전송을 방지합니다.
4
재고수량 역동기화: 이카운트 재고 데이터를 상품정보 시트 G열(재고수량)로 실시간 반영하는 역방향 파이프라인을 구축합니다.
5
단가 다이렉트 전송: 상품정보 시트에서 단가를 수정하고 버튼을 누르면 변경값+품목코드만 추출하여 이카운트 API로 직접 전송하는 원클릭 기능을 개발합니다.

⚠️ 기술 리스크 및 대응 설계

Core System #3

협력업체 30개사 자동 연동 시스템 구축 계획

대리공급/위탁 협력업체에 발주를 자동 배분(Push)하고, 업체가 기입한 송장번호를 자동 수집(Fetch)하는 양방향 데이터 통신 시스템을 설계·구축합니다.

📤 Push 시스템 설계

1
독립배포 시트 자동 생성: 업체별 전용 구글 스프레드시트를 자동 생성하고, 메타데이터(AA1:업체명, AB1:거래처코드, AC1:시트ID)를 자동 기록합니다.
2
Prefix 라우터: 이카운트 품목코드 앞 2자리로 해당 협력업체를 자동 식별하여 전용양식 탭으로 발주를 Push하는 라우팅 엔진을 개발합니다.
3
복합 고유키 대조: UID|코드 형태의 복합키를 생성하여 중복 Push를 물리적으로 차단하는 무결성 엔진을 구현합니다.
4
상품 검색 사이드바: 협력업체 시트에서 사용할 300ms 디바운스 실시간 검색 사이드바 UI를 설계합니다. 검색 결과 클릭 시 C열(이카운트코드)에 자동 입력됩니다.

📥 Fetch 시스템 & 정산 설계

1
송장 역수집 모듈: 업체가 A열에 송장번호를 기입하면 자동 감지하여 중앙 시트 X열에 기록하고, 진행상태를 '발주완료' → '송장수집'으로 전환합니다.
2
연락처 0 보호 로직: 수취인 번호의 앞자리 0이 엑셀에서 소실되는 것을 방지하기 위해 해당 열 포맷을 텍스트형(@)으로 강제 고정합니다.
3
Gmail 송장 파서: 비협력업체가 이메일로 보내는 송장번호를 자동 파싱하여 매칭하는 _partnerGmailInvoice.gs를 개발합니다.
4
월별 자동 정산: 당월 정산 탭 자동 생성 → 대사 확인 → 보관본 아카이브 3단계 정산 파이프라인을 구축합니다.
개발 파일: _partnerOrders.gs, _partnerExclusivePush.gs, _partnerHelpers.gs, _partnerGmailInvoice.gs, _partnerMonthlySettle.gs, _partnerMenu.gs, _partnerDeploy.gs, priceManager.gs 등
배포 대상: 30개 협력업체 독립 시트
개발 기간: 6~8주 (가장 복잡한 모듈)

AI System #1

AI 제품 이미지 자동 생성 시스템 구축 계획

일회용 용기·위생용품의 단조로운 누끼 사진을 Gemini Vision API를 활용해 감성적인 화보 연출 이미지로 자동 변환하는 AI 시스템을 개발합니다.

📸 GAS 기반 AI 이미지 메이커 설계

  • 구현 방식: 구글시트 사이드바 UI에서 직접 실행되는 Apps Script + Gemini Vision API 연동
  • 핵심 기능: 누끼 사진 업로드 → AI가 재질을 감지하고 카페·주방·테이블 등 배경을 자동 합성
  • 다중 화보 생성: 1장의 원본에서 10가지 다른 배경 연출샷을 한 번에 생성
  • 드라이브 자동 저장: 생성된 이미지를 구글 드라이브 폴더에 자동 정리·저장

  • Script Lock 설계: 다중 메뉴 동시 호출 충돌 방지 락 메커니즘 구현
  • Dead Letter Queue: 실패 트랜잭션 전용 큐 적재 → 복구 시 일괄 처리
  • 롤백 스위치: API 장애 시 기존 수동 작업 탭 즉시 스위칭 시나리오 확보
