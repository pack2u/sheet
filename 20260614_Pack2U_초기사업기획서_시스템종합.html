Executive Summary

사업 비전 및 핵심 요약

현재 문제 진단: 수작업 번아웃

30개 대리공급/위탁 업체와의 파편화된 발주 취합, 수동 송장 매핑, 수기 상세페이지 제작에 전체 인력·시간의 75%를 유실하고 있습니다.

  • 매일 4.5시간: 엑셀 업로드·수기 데이터 매칭 소모

해결 방향: AI 기반 무인 자동화 생태계

  • Zero-Touch 물류: 주문→ERP→WCS→로봇 피킹 100% 무인
  • AI 비주얼: 1분 만에 화보 10장 + 상세페이지 코드 생성

  • 지능형 CS: RAG AI 챗봇이 고객문의 1차 방어

Core Engine

상품정보시트 — 전사 운영의 중추 신경 시스템

26개 이상의 Apps Script 모듈이 유기적으로 맞물려 작동하는 구글 스프레드시트 기반 통합 운영 플랫폼입니다. 주문 수집부터 ERP 전표, 송장 분배, 정산 마감까지 전 과정을 단일 시트에서 자동 처리합니다.

B2B Vendor Hub

협력업체 30개사 자동 연동 메커니즘

📤 발주 Push 시스템

  • 이카운트 코드 Prefix 감지: 품목코드 앞 2자리로 협력업체 자동 라우팅
  • 복합 고유키 (UID|코드): 중복 Push 물리적 차단
  • 독립배포 시트: 업체별 전용 스프레드시트 자동 생성·배포
  • 메타 데이터: AA1(업체명), AB1(거래처코드), AC1(시트ID) 자동 기록
  • 상품 검색 사이드바: 300ms 디바운스 실시간 검색 → C열 자동 입력

📥 송장 Fetch & 정산 자동화

  • 송장 역수집: 업체가 A열에 송장 기입 → 자동 감지 → X열 기록 + 상태 전환
  • 연락처 0 보호: 수취인 번호 앞자리 0 소실 방지 — 텍스트형(@) 강제 유지
  • Gmail 송장 수집: 비협력업체 이메일 송장을 자동 파싱
  • 월별 정산: 당월 정산 탭 자동 생성 → 대사 확인 → 보관본 생성
  • CUST_CD 매핑: 업체등급단가매핑 시트 자동 갱신, 미입력 행 빨간색 경고

ERP Integration

이카운트 ERP 완전 통합 브리지

🔗 API 연동 파이프라인

3단계 인증 + 비동기 전송 아키텍처로 안정적 ERP 동기화를 달성합니다.

  • 세션 관리: PropertiesService 안전 보관 — 특수문자(%, +) 인코딩 손상 방지
  • HTTP 412 방어: IIS 서버의 Expect: 100-continue 거부 → 명시적 빈 헤더 추가
  • 품목그룹3 코드표: 9001(판매중)~9007(소싱중) 7단계 상태 체계
  • P열 중복 차단: 이카운트 업 완료 플래그 마킹으로 이중 갱신 원천 방어

재고수량 동기화이카운트 API → 이카운트-재고 탭 → moveToEcount.gs → 상품정보 G열(재고수량)

🎯 핵심 기능 설계

  • 이미지→영상 변환: Gemini Veo 3 / Runway Gen-4 / Sora API를 활용해 정지 이미지에 카메라 무빙·줌·팬·틸트 자동 적용

  • BGM 매칭: 제품 무드에 맞는 로열티 프리 BGM 자동 선곡·합성
  • 멀티 포맷 출력: 인스타 릴스(9:16), 유튜브 쇼츠(9:16), 쿠팡 영상(1:1), 썸네일 등

  • 영상 생성 엔진: Gemini Veo 3 (구글 네이티브 최우선) → Runway Gen-4 (폴백)
