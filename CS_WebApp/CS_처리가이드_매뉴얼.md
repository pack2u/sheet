# Pack2U CS 처리 가이드 (v1)

> CS앱 우측 **처리가이드 · CS사례** 패널에 내장된 공식 플레이북입니다.  
> 시트 매뉴얼·AppSheet CS목록과 함께 검색되며, **처리가이드가 검색 결과 상단에 우선** 표시됩니다.

## 검색 팁

| 검색어 예시 | 해당 가이드 |
|------------|------------|
| 반품, 변심, 환불 | 단순 변심 반품 |
| 오배송, 잘못, 다른색 | 오배송 반품 |
| 불량, 파손 | 불량·파손 반품 |
| 수량, 누락, 덜 | 수량 부족 |
| 교환, 옵션 | 교환 |
| 취소, 출고전 | 출고 전/후 취소 |
| 지연, 안옴 | 배송 지연 |
| 미수령, 분실 | 미수령·분실 |
| 제주, 도서산간 | 추가배송비 |
| 반품대장, 상담 | 반품관리대장 사용법 |

카테고리 칩(반품·교환·취소·환불·배송·클레임)으로 필터 가능.

---

## 1. 반품

### 1-1. 단순 변심 반품
- **언제:** 수령 후 변심 반품
- **상태:** 접수 → 수거요청 → 수거중 → 반품입고 → 입고검수 → 환불처리 → 완료
- **핵심:** 주문검색 확인 → 반품대장(단순반품) → 수거 안내 → 입고검수 → 환불 → 이카운트 ok
- **주의:** 개봉·사용 흔적 시 업체 반품규정 확인

### 1-2. 오배송 반품
- **핵심:** 주문 vs 실수령 대조, 사진 필수, 정품 재발송과 반품 환불 이중 처리 방지

### 1-3. 불량·파손
- **핵심:** 불량 사진 필수, 입고검수 후 환불/재출고, 식품·위생용품 개봉 여부 확인

### 1-4. 수량 부족
- **핵심:** 주문수량 vs 실수령, 재출고 또는 차액환불

### 1-5. 부분 반품
- **핵심:** 반품 수량·금액 명시, 행별 분리

---

## 2. 교환 · 취소 · 환불

### 2-1. 교환
- 재고 확인 → 수거(필요) → 재출고, 변심 vs 오배송 비용 구분

### 2-2. 출고 전 취소
- 송장 없음 확인 → 출고 hold → PG/몰 환불

### 2-3. 출고 후 취소
- 반품 프로세스로 전환, 왕복배송비 안내

### 2-4. 입고 후 환불
- 입고검수 완료 후 환불, 선환불 금지(예외 제외)

---

## 3. 배송 · 기타

### 3-1. 배송 지연 / 3-2. 미수령·분실 / 3-3. 송장 오류
- 주문검색·택배 추적 → 원인별 안내 → 재출고/환불

### 3-4. 도서산간 추가배송비
- 주소·선결제 확인 → 차액 안내/환불

### 3-5. 대리·타공급 건
- 공급처 전용양식·송장 경로 확인

### 3-6. 강성 클레임
- 사실관계 정리 → 약속 시간 회신 → 에스컬

### 3-7. 사진·증빙 (AppSheet)
- 바코드/송장 → AppSheet 촬영 → 확인 후 본 처리

---

## 4. CS앱 · 시트 연동

| 데이터 | SSOT | CS앱 |
|--------|------|------|
| 반품 상태·상담 | Google 시트 `반품관리대장` | 가운데 반품 패널 |
| 과거 CS | AppSheet `CS목록` | 처리가이드 패널 하단 사례 |
| 주문·송장 | 일일마감 | 좌측 검색 |
| 공식 매뉴얼 | 매뉴얼 DB 시트 | 검색 시 보조 |

**반품대장:** M열=처리상태, N열=상담 이력(타임스탬프 자동). CS앱에서 변경 시 시트 즉시 반영.
