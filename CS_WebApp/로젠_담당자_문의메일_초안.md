당사 고객관리(CS) 시스템에 로젠 Open API를 연동하여 **배송조회와 반품접수**를
처리하고자 합니다. openapihome.ilogen.com 의 개발가이드와 API Docs를 확인하였으며,
개발 착수에 앞서 아래 사항을 문의드립니다.

---

### 1. 호출자 IP 검증 관련 (가장 중요)

당사 CS 시스템은 **Google Apps Script 기반 웹앱**으로 구축되어 있습니다.
이 환경은 외부 API 호출 시 발신 IP가 Google 공용 대역에서 **유동적으로 배정**되어,
특정 IP를 고정하여 등록하는 것이 불가능합니다.

아래 중 가능한 방식이 있는지 확인 부탁드립니다.

- ① 인증키(secretKey)만으로 인증하고 **IP 검증을 면제**받는 방식
- ② IP 대역(CIDR) 단위 등록이 가능한지
- ③ 위 두 가지가 모두 불가하다면, 고정 IP를 보유한 **중계 서버를 별도로 구축**해야 하는지

이 답변에 따라 당사의 개발 범위와 일정이 달라지므로, 우선적으로 확인 부탁드립니다.

### 2. 일일 호출 한도

개발가이드에 호출 건수 제한이 명시되어 있지 않습니다.
**일일 또는 분당 호출 상한**이 있는지, 있다면 초과 시 동작(차단 또는 지연)이
어떻게 되는지 알려주시면 캐싱 설계에 반영하겠습니다.

### 3. userId(연동업체코드) 확인

API Docs에 *"연동업체코드가 아닌 경우 거래처코드 입력"* 으로 안내되어 있습니다.
당사는 별도 연동업체를 통하지 않고 **화주사가 직접 개발**하는 형태입니다.

- 이 경우 `userId` 에 당사 거래처코드를 입력하는 것이 맞는지
- 연동업체코드가 별도로 발급되는 것이라면 그 발급 절차

확인 부탁드립니다.

### 4. 개발계(topenapi) 테스트 범위

당사 거래처코드로 **개발계에서 화물추적·반품 API 테스트가 가능한지** 궁금합니다.

개발계에 당사 실데이터가 없거나 별도 **연계 등록**이 필요한 API가 있다면
해당 절차를 미리 안내해 주시기 바랍니다.
테스트코드로만 호출 가능한 API가 있다면 그 부분도 함께 알려주시면 감사하겠습니다.

### 5. 화물상태(statNm) 값 목록 (중요)

화물추적 조회 응답의 `statNm` 이 코드가 아닌 **한글 문자열**로 내려옵니다.

- 현재 사용 중인 **상태 문자열 전체 목록**을 받을 수 있는지
- 향후 문구가 변경될 경우 **사전 공지**가 이루어지는지

확인 부탁드립니다. 당사 시스템에서 배송 상태를 판정하는 기준이 되는 값이라
목록 확보가 필요합니다.

### 6. 반품 API 사용 조건

- 반품 접수 등록(`registReturnRequest`) 사용에 **별도 계약이나 승인**이 필요한지
- 2026.04.29 자로 운임타입이 **선불(010)·착불(020)** 로 제한된 것으로 확인했는데,
  당사 계약 기준으로 반품 접수 시 적용 가능한 운임타입

확인 부탁드립니다.

### 7. 신청 절차

- **TEST Key** 발급을 위한 시스템연동신청서 양식 및 제출처
- **Live Key** 전환 시 검수 절차와 예상 소요 기간

안내 부탁드립니다. 일정 수립에 참고하겠습니다.
