### 1. 운영 환경의 호출 IP (가장 중요)

당사 운영 시스템은 **Google Apps Script 기반 웹앱**입니다.
이 환경은 외부 API 호출 시 발신 IP가 Google 공용 대역에서 **유동적으로 배정**되어
특정 IP를 고정해 등록하는 것이 불가능합니다.

- 개발 단계는 **사내 IP(14.34.200.225)** 로 신청등록하여 진행할 예정입니다.
- 다만 **운영 단계**에서는 이 IP로 호출이 나가지 않습니다.

아래 중 가능한 방식이 있는지 확인 부탁드립니다.

- ① 인증키(secretKey)만으로 인증하고 **IP 검증을 면제**받는 방식
- ② **IP 대역(CIDR) 단위 등록**이 가능한지
- ③ 위가 모두 불가하여 **고정 IP 중계 서버를 별도로 구축**해야 하는지

③이라면 그렇게 준비하겠습니다. 다만 구축 여부가 일정과 비용에 직접 영향을 주어
먼저 확인드립니다.

### 2. 주문등록을 사용하지 않는 경우의 절차

당사는 이번 연동에서 **화물추적과 반품만** 사용할 예정입니다.
자사 출고 주문 등록은 현재 별도 경로로 처리하고 있어
`/registerOrderData` 는 사용 계획이 없습니다.

안내해 주신 절차에는 *"개발 환경에서 `registerOrderData` 호출 성공을 확인한 후
오픈등록을 신청"* 으로 되어 있습니다.

- 주문등록을 쓰지 않는 경우에도 이 단계가 필요한지
- 필요하다면 `/inquiryCargoTrackingMulti` 호출 성공 확인으로 갈음이 가능한지

확인 부탁드립니다.
