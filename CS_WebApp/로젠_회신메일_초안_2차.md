### 1. 도메인 기반 등록 방식

도메인 등록이 가능하다는 안내 감사합니다. 다만 전달드릴 값을 확정하기 위해
**검증 방식**을 먼저 확인하고 싶습니다.

당사 운영 시스템은 **Google Apps Script 기반**이라, 외부 API 호출이
당사 도메인(`pack2u.co.kr`)이 아니라 **Google 인프라에서 발신**됩니다.
즉 당사 서비스 도메인은 「접속받는 주소」일 뿐, 「호출해 나가는 주소」가 아닙니다.

실제 발신 구간을 측정한 결과는 다음과 같습니다.

| 항목 | 측정값 |
|---|---|
| 발신 IP | `34.116.22.3` |
| 소유 대역 | Google (`34.64.0.0 ~ 34.127.255.255`) |
| 역방향 도메인(PTR) | **없음** (조회 시 REFUSED) |

즉 **등록할 도메인 자체가 조회되지 않으며**, 해당 대역은 약 400만 개 IP 규모라
대역 단위 등록도 현실적이지 않은 상황입니다.

확인 부탁드릴 사항입니다.

- 도메인 등록은 **수신된 IP를 역방향 조회(PTR)하여 대조**하는 방식인지,
  아니면 다른 기준(요청 헤더, 별도 식별자 등)으로 검증하는지
- 위와 같이 PTR이 존재하지 않는 경우에도 등록이 가능한 방법이 있는지

만약 이 방식으로는 등록이 어렵다면, 당사가 **고정 IP를 가진 중계 서버를 별도로
구축**하여 그 IP를 등록하는 방향으로 진행하겠습니다.
어느 쪽이 가능한지만 알려주시면 그에 맞춰 준비하겠습니다.

### 2. 개발계 테스트 미지원에 따른 진행 방법

화물추적·반품 API가 개발계에서 지원되지 않는다는 점 확인했습니다.
그렇다면 아래와 같이 이해하면 되는지 확인 부탁드립니다.

- 당사는 개발계에서 검증할 대상이 없으므로, **[오픈등록]을 바로 신청**하고
  운영 Key를 받아 운영 환경에서 연동을 진행하면 되는지
- 화물추적은 조회성이라 운영 호출에 부담이 없을 것으로 보이나,
  **반품 접수(`registReturnRequest`)는 운영 호출 시 실제 접수가 발생**합니다.
  연동 검증 목적의 테스트 접수를 어떻게 진행하면 되는지 권고 사항이 있으신지
  (예: 테스트 후 `cancelReserveState` 로 취소하면 집하가 나가지 않는지,
  또는 별도 테스트용 거래처코드를 받을 수 있는지)

실제 집하가 나가는 일이 없도록 하고 싶어 미리 여쭙습니다.
