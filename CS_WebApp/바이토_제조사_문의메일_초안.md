안녕하세요, 바이토 통화관리솔루션을 사용 중인 팩투유(Pack2U)입니다.
지난번 API 연동을 여쭤봤을 때 「자체적으로 구성하라」는 답변을 받아,
현재는 프로그램의 **통화내역·문자내역 「내보내기」(엑셀)** 를 정기적으로 받아
사내 CS 시스템에 반영하고 있습니다. 덕분에 부재중 콜백과 고객 문의 처리가
한결 빨라졌습니다.

운영하면서 네 가지를 확인하고 싶어 연락드립니다.

**1. 「웹 API 활성화」 기능 사용 가능 여부**
PC 프로그램 안에 「웹 API 활성화」라는 설정 항목이 있는 것으로 압니다.
저희 계정에서 이 기능을 사용할 수 있는지, 가능하다면 사용 방법이나 연동 문서를
받을 수 있을지 여쭙습니다. 내보내기 방식보다 안정적이고 실시간에 가까워
고객 응대에 큰 도움이 될 것 같습니다. 유료라면 비용도 알려 주시면 검토하겠습니다.

**2. 통화 받아쓰기(STT)·AI 요약의 내보내기**
현재 통화내역 내보내기에는 발신·수신번호, 일시, 결과만 들어 있고
녹취 받아쓰기와 AI 요약은 빠져 있습니다. 이 내용도 내보내기(엑셀/CSV)에
포함하거나, 별도로 받을 수 있는 방법이 있을까요?

**3. 현재 방식의 지속 사용 확인**
지금은 CS PC에서 새 전화·문자가 오면 1~2분 안에, 그리고 30분마다 한 번씩
프로그램의 내보내기 기능을 자동으로 실행해 엑셀을 받고 있습니다
(프로그램 파일이나 데이터는 수정하지 않습니다).
이 방식을 계속 써도 이용 약관이나 서비스에 문제가 없는지 확인 부탁드립니다.
또 정해진 시간에 자동으로 내보내기 파일을 저장하는 기능이 있다면 알려 주세요.

**4. KT 통화매니저의 외부 연동 규격 (POS·CRM 연동)**
바이토 통화관리솔루션이 KT 「통화매니저」로 제공되는 것으로 알고 있습니다.
KT가 통화매니저를 오케이포스 POS와 연동해, 전화가 오면 POS 화면에 발신 번호와
고객 정보·최근 주문을 띄워 주는 서비스를 제공한다는 기사를 보았습니다.
이처럼 **전화가 올 때 발신 번호를 외부 프로그램에 넘겨주는 연동 규격**(CTI·CID 연동)이
있다면, 저희 사내 CS 시스템도 같은 방식으로 붙일 수 있을지 여쭙습니다.
- 사용할 수 있다면 신청 방법과 연동 문서
- 바이토가 아니라 KT 쪽에 신청해야 한다면 그 창구
- 수신뿐 아니라 통화 종료·부재중·문자 수신 같은 알림도 받을 수 있는지

참고로 저희는 회선 5개(031-923-7794 · 7795 · 7796, 070-4225-9261, 070-4228-0914)를
사용하고 있습니다.
