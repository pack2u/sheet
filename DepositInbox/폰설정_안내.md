# 입금 폰 설정 안내 (MacroDroid) — 따라 하기

> 20분 정도 걸립니다. 한 번만 하면 됩니다.
> 앱 화면이 영어로 나오면 괄호 안의 영어 이름을 찾으세요.

---

## 준비물

- 은행 입금 문자를 받는 **안드로이드 폰**
- PC 의 **`DepositInbox\_폰주소.txt`** 파일 — 주소 2개가 들어 있습니다 (①문자용, ②신호용)

### 주소를 폰으로 옮기기
주소가 길어서 폰에서 직접 치면 틀립니다. **복사해서 옮기세요.**

1. PC 에서 `_폰주소.txt` 를 엽니다
2. **① 주소**를 통째로 복사 → **카카오톡 「나와의 채팅」**에 붙여넣어 보냅니다
3. **② 주소**도 똑같이 보냅니다
4. 폰의 카카오톡에서 **꾹 눌러 복사**해서 쓰면 됩니다

> ⚠ 이 주소에는 비밀 열쇠(토큰)가 들어 있습니다. **다른 사람 채팅방에는 보내지 마세요.**

---

## 1단계. 앱 설치와 폰 설정 (5분)

1. **플레이스토어** → `MacroDroid` 검색 → **설치** → 열기
2. 처음 화면 안내는 **건너뛰기** 해도 됩니다
3. **배터리 설정** — 이걸 안 하면 폰이 앱을 재워서 문자를 놓칩니다
   - 폰 **설정** → **애플리케이션** → **MacroDroid** → **배터리** → **「제한 없음」**
   - (삼성폰) 설정 → **배터리** → **백그라운드 사용 제한** → **「절전 예외 앱」**에 MacroDroid 추가

---

## 2단계. 매크로 ① — 은행 문자 보내기 (10분)

MacroDroid 첫 화면에서 **「매크로 추가」(Add Macro)** 를 누릅니다.
화면이 **트리거 / 액션 / 제약 조건** 세 칸으로 나뉘어 있습니다.

### ⓐ 트리거 — "언제"

1. **트리거** 칸의 **＋** 를 누릅니다
2. **「전화/SMS」** (Call/SMS) → **「SMS 수신」** (SMS Received)
3. 「누구에게서?」 → **「모든 연락처」** (Any Contact) 를 고르고 **확인**
   - 은행 번호만 고르면 더 좋지만, 처음에는 이게 쉽습니다. 서버가 입출금 문자가 아닌 것은 걸러 냅니다
4. 「내용」 → **「모두」** (Any) → **확인**
5. 문자 읽기 **권한을 물어보면 「허용」**

### ⓑ 액션 — "무엇을"

1. **액션** 칸의 **＋** 를 누릅니다
2. **「연결」** (Connectivity) → **「HTTP 요청」** (HTTP Request)
   - 안 보이면 위쪽 🔍 검색에 `HTTP` 를 칩니다
3. **「설정」** 탭
   - **요청 종류**: **POST**
   - **URL 입력**: `_폰주소.txt` 의 「입금문자전송 — URL」 (`…/exec` 로 끝나는 짧은 주소)
4. **「Body 내용」** 탭
   - **본문 보내기**를 켭니다
   - **콘텐츠 유형**: **text/plain**
   - 본문 칸에 `_폰주소.txt` 의 「Body 내용」 줄을 **통째로** 붙여넣기
     → `dp:……… [sms_message]` 모양. 뒤의 `[sms_message]` 가 문자 내용으로 바뀌어 나갑니다
   > ★ 왜 토큰을 본문에? MacroDroid 는 본문을 보낼 때 주소의 `?` 뒷부분을 떼어 버린다(2026-09-28 확인).
   > 본문은 온전히 도착하므로 토큰을 본문 맨 앞에 싣는다.
5. 오른쪽 위 **✓(저장)**

### ⓒ 저장
- 맨 위 이름 칸에 **`입금문자 전송`** → 오른쪽 아래 **저장(✓)**
- 제약 조건은 **비워 둡니다**

---

## 3단계. 매크로 ② — 살아 있다는 신호 (3분)

폰이 꺼지면 입금이 와도 모릅니다. 30분마다 "살아 있어요" 신호를 보내서, 끊기면 챗으로 알려 줍니다.

1. **「매크로 추가」**
2. **트리거 ＋** → **「날짜/시간」** (Date/Time) → **「일정 간격」** (Regular Interval) → **30분** → 확인
3. **액션 ＋** → **「연결」** → **「HTTP 요청」**
   - 요청 방법: **POST**
   - URL: 카카오톡에서 복사한 **② 주소**
   - 본문은 **안 넣어도 됩니다**
4. 이름 **`입금폰 신호`** → **저장**

---

## 4단계. 시험 (2분)

1. 두 매크로가 목록에서 **켜짐**(스위치 파란색)인지 확인
2. **다른 통장에서 1,000원**을 입금합니다
3. 구글챗 **「입금알림」 방**에 `💰 입금 1,000원 · 이름` 카드가 오면 **끝!**

### 안 올 때

| 증상 | 할 일 |
|---|---|
| 아무것도 안 옴 | MacroDroid → 왼쪽 메뉴 → **「시스템 로그」** 에서 HTTP 요청이 나갔는지 확인. 캡처해서 보내 주세요 |
| 로그에 요청이 없음 | `[Web발신]` 이 붙은 **긴 문자는 SMS 트리거가 못 잡는 폰**이 있습니다 → 아래 「대신 쓰는 방법」 |
| 「❓ 읽지 못한 은행 문자」가 옴 | 연결은 된 것입니다. 그 문자 내용을 보내 주시면 해석을 맞춥니다 |

### 대신 쓰는 방법 — 알림으로 잡기
매크로 ①의 **트리거만** 바꿉니다.

1. 트리거를 지우고 **＋** → **「앱」**(Applications) 또는 **「기기 이벤트」** → **「알림 수신」** (Notification Received)
2. 앱: **메시지** (삼성 메시지 또는 Google 메시지)
3. 알림 내용: **「포함」** → `입금`
4. 액션의 본문 매직 텍스트를 **「알림 내용」** (Notification text, `[notification]`) 으로 바꿉니다
5. MacroDroid 에 **알림 접근 권한 허용**
