안녕하세요. 주식회사 팩투유입니다.
9월 11일부터 로젠택배로 전환하여 출고하고 있습니다.

저희는 주문 접수부터 송장 출력까지를 자체 시스템으로 처리합니다.
하루 세 번 출고가 나가고, 도서산간은 주문받는 «그 자리에서» 고객에게
추가운임을 안내하고 동의를 받은 뒤에만 내보냅니다.
그래서 아래 두 가지가 필요합니다.


─────────────────────────────────────────────────
[1] 도서산간 추가운임(도선료) 표
─────────────────────────────────────────────────

  지금은 이전 택배사 기준 표가 시스템에 그대로 들어 있어, 로젠
  청구액과 다른 금액을 고객에게 안내하고 있을 수 있습니다.
  엑셀·PDF·이미지 어느 쪽이든 좋습니다. 다음이 들어 있으면 됩니다.

   ① 지역 구분 — 시/도 · 시군구 · 읍면동, 필요한 곳은 리 단위까지
   ② 지역별 금액
   ③ 우편번호 목록이 있으면 «그쪽이 더 좋습니다»
      저희 시스템은 주소가 아니라 우편번호로 도서산간을 가립니다.
   ④ 제주 항공 할증이 별도인지, 금액은 얼마인지
   ⑤ 우도면·추자면처럼 «항공료에 배편 삯이 더 붙는» 곳이 있는지
      (더해서 받는지, 둘 중 큰 것만 받는지)
   ⑥ 도서산간 중 위탁배송(대리점 인계) 구간이 따로 있는지, 요금이 다른지
   ⑦ 반품·회수도 같은 금액인지

─────────────────────────────────────────────────
[3] OPEN API 사용 신청
─────────────────────────────────────────────────

  로젠 OPEN API 문서(openapihome.ilogen.com)는 확인했습니다.
  주문등록 · 반품접수 · 화물추적 · 계약운임 조회를 쓰려고 합니다.

  ▸ 신청 절차
     1. 이용 신청에 필요한 서류와 절차를 알려주세요.
     2. 거래처(계약) 코드와 API 인증정보(키·ID) 발급을 부탁드립니다.
     3. 개발계(topenapi.ilogen.com) 계정을 먼저 받고 싶습니다.
        운영계(openapi.ilogen.com) 전환 조건과 걸리는 기간도 알려주세요.
     4. 시험용 운송장 번호 대역을 따로 주시는지.

  ▸ 운송장번호 (저희에게 가장 중요합니다)
     5. 주문등록 응답에 «운송장번호가 바로» 오는지,
        아니면 채번을 따로 요청해야 하는지.
        — 저희는 송장 출력과 동시에 쇼핑몰·거래처에 번호를 넘겨야 합니다.
     6. 운송장번호가 11자리가 맞는지, 앞자리 대역이 정해져 있는지.
        (저희 시스템이 번호만 보고 택배사를 가립니다)
     7. 체크섬 같은 검증 규칙이 있으면 알려주세요.
        바코드 오독을 걸러내는 데 씁니다.

  ▸ 출력·양식
     8. 운송장(라벨) 출력 규격과 필수 항목.
        지금은 택배사 양식 엑셀을 만들어 올리는 방식입니다.
     9. 엑셀 업로드 양식도 함께 주시면 좋겠습니다 —
        API 전환 전까지는 그쪽을 씁니다.

  ▸ 운임
    10. dlvFare(택배운임)가 필수이고 0·null 이 안 된다고 돼 있습니다.
        저희는 신용(월정산) 거래인데 이 칸에 무엇을 넣어야 하는지.
    11. 계약운임 조회 API 로 «도서산간 할증까지» 받을 수 있으면
        [1]번 표 대신 그것을 쓰겠습니다. 가능한지 알려주세요.

  ▸ 반품·회수
    12. 반품 접수 시 접수번호(takeNo)만 오고 운송장번호는 별도
        조회가 맞는지. 맞다면 번호가 붙는 데 보통 얼마나 걸리는지.
    13. 접수한 반품을 «취소»하는 방법.

  ▸ 주소·운영
    14. 주소정제 또는 우편번호 조회 API 가 있는지.
        없다면 배송불가 지역은 저희가 걸러야 하니 기준을 알려주세요.
    15. 하루 호출 한도와 초당 제한.
    16. 장애·문의를 받는 곳(기술 담당 연락처).
