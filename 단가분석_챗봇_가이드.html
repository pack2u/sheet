⚠️ 필수 점검
🔴 마진 이상 품목 탐지
전체 상품의 마진율을 스캔하여 기준 이하 품목을 찾아냅니다. 역마진(원가 > 판매가)도 자동 감지합니다.
이렇게 물어보세요
"마진 15% 미만 찾아줘"
"마진율 낮은 품목 알려줘"
"역마진 있는 거 있어?"
→ 결과: 마진율 낮은 품목 테이블 (품목코드, 품목명, 판매가, 원가, 마진율) 출력
📊 비교 분석
💱 채널별 가격 차이 비교
자사몰 vs 오프라인, 자사몰 vs 쿠팡, 또는 임의의 두 열의 가격 차이를 분석합니다.
이렇게 물어보세요
"자사몰과 쿠팡 가격 차이 확인해줘"
"오프라인 단가 비교 20% 이상"
"W열과 BN열 비교해줘"
→ 결과: 편차 큰 품목 리스트 + 차이율(%) 표시. 🔴-30% 🟡+25%
🚨 데이터 품질
📝 미입력 항목 탐지
판매가, 매입가, 품목코드, 재고수량 중 비어있는 항목을 한눈에 파악합니다.
이렇게 물어보세요
"비어있는 항목 찾아줘"
"누락된 데이터 확인"
"판매가 미입력된 거"
→ 결과: 품목별 비어있는 항목 (예: "판매가, 재고수량") 표시
🔎 검색
🏷️ 품목 검색 & 상세 조회
이카운트 코드나 품목명으로 검색하면 해당 품목의 전체 정보를 카드 형태로 표시합니다.
이렇게 물어보세요
"JHCRJJIM0001 찾아줘"
"한우갈비 검색"
"최고갈비 정보 알려줘"
→ 결과: 상태, 코드, 품목명, 출고지, 구매처, 재고, 매입가, 판매가, 마진율 카드
📈 현황
📊 전체 요약 & 상태별 현황
전체 품목 수, 판매중/품절/단종 비율, 미입력/마진 이상 건수를 한눈에 요약합니다.
이렇게 물어보세요
"전체 현황 알려줘"
"단종품 몇 개야?"
"품절 목록 보여줘"
→ 결과: 총 품목 1,200개 | 판매중 850 | 품절 120 | 단종 230 | 마진↓ 45
🛡️ 종합 점검
✅ 전체 자동 검증 (7가지)
한 번에 7가지 항목을 자동 검증합니다: 코드 누락, 판매가 0, 매입가 0, 역마진, 저마진, 재고 0+판매중, 채널 가격 편차
이렇게 물어보세요
"이상한 부분 확인해줘"
"전체 검증 돌려줘"
"문제 있는 품목 찾아줘"
→ 결과: 이슈 유형별 리스트 (역마진 3건, 코드 누락 5건, 재고 0 판매중 12건...)

수정 & 일괄 처리 기능
수백 개 품목의 가격을 자연어 한 줄로 수정 — 미리보기 확인 후 반영
⭐ 핵심 기능
🎯 마진 목표 역산 수정
목표 마진율을 입력하면 매입가 기준으로 판매가를 자동 계산합니다.
판매가 = 매입가 ÷ (1 - 목표마진)
이렇게 물어보세요
"마진 30%로 맞춰줘"
"마진 10% 미만 품목 마진 25%로 맞춰줘"
"단종품 제외 마진 20%로 일괄 변경"
→ 동작: 매입가 10,000원인 품목 → 마진 30% → 판매가 14,286원으로 자동 계산
📐 비율 조정
📈 % 기반 일괄 인상/인하
전체 또는 조건에 맞는 품목의 판매가를 % 단위로 올리거나 내립니다.
이렇게 물어보세요
"판매가 5% 올려줘"
"쿠팡판매가 10% 내려줘"
"마진 15% 미만 판매가 8% 인상"
→ 동작: 현재 50,000원 → 5% 인상 → 52,500원 (미리보기 후 확인)
🔢 고정값
💰 고정 금액 일괄 설정
특정 조건의 품목들을 동일한 금액으로 일괄 변경합니다.
이렇게 물어보세요
"JHCRJJIM0001 판매가 85000으로 수정"
"품절 품목 재고 0으로 변경"
→ 동작: 지정된 품목의 해당 열을 고정 금액으로 변경
🏷️ 다중 코드
📋 복수 품목 지정 수정
여러 이카운트 코드를 나열하면 해당 품목들만 선택적으로 수정합니다.
이렇게 물어보세요
"JHCRJJIM0001 JHCRJJIM0002 JHCRJJIM0003 판매가 5% 올려줘"
"ABCDE00001 FGHIJ00002 상태 품절로 변경"
→ 동작: 지정된 코드만 필터링 → 미리보기 → 확인 후 반영
🔄 상태 변경
📌 상태 일괄 변경
조건에 맞는 품목들의 상태(판매중/품절/단종품)를 한번에 변경합니다.
이렇게 물어보세요
"재고 0인 품목 품절로 변경해줘"
"단종품을 판매중으로 바꿔줘"
→ 동작: 조건 필터 → 상태 열 일괄 변경
🤖 AI 추천
🧠 AI 자동 수정 제안
Gemini가 전체 데이터를 분석하여 문제점을 찾고, 원클릭 수정 버튼과 함께 제안합니다.
이렇게 물어보세요
"수정할 부분 제안해줘"
"이상한 부분 고쳐줘"
"어떤 부분을 수정하면 좋을까?"
→ 동작: AI가 역마진/저마진/누락 데이터 분석 → 수정 제안 + [반영하기] 버튼 생성

조건 조합이 가능합니다
