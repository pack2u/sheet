# 세트분리 시험 돌리는 법

```
cd 세트분리V2/node
node _fee_test.mjs          # 하나만
for f in *_test.mjs; do node "$f"; done    # 전부
```

## ★ 반드시 `node/` 안에서 돌린다 ★

시험이 원본을 **cwd 기준**으로 읽는다(`readFileSync("../core.js")`).
한 칸 위(`세트분리V2/`)에서 돌리면 `Pack2U_상품정보sheet/core.js` 를 찾아
`ENOENT` 로 통째로 터진다 — 「시험이 깨졌다」로 보이지만 못 찾은 것뿐이다.

2026-10-07 에 열 개가 그렇게 보였고, 그중 여섯은 자리만 옮기니 바로 통과했다.

## 시험이 울면 «코드»부터 의심하지 말 것

나머지 넷은 전부 **시험이 옛 약속을 들고 있던 것**이었다. 코드 결함은 없었다.

| 시험 | 울던 까닭 |
|---|---|
| `_bulkbox` | `u.조건ID` → `조건칸` (샘플만 조건 하나로, 2026-09-21). 글자로 찾고 있었다 |
| `_islandskip` | 도선료 6,500 → 5,000 통일. 금액을 못 박아 두었다 |
| `_verifysplit` | 「한 줄만 있어도 안 막는다」 → 2026-09-21 에 «막는다»로 뒤집힘 |
| `_owntabs` | 「재실행일 때만 걷는다」 → 2026-09-28 에 «늘 걷는다»로 뒤집힘 |

그래서 고칠 때는 **글자가 아니라 뜻**을 못 박는다. 글자를 통째로 찾으면
멀쩡한 리팩터링에도 울고, 우는 시험은 아무도 안 보게 된다.
